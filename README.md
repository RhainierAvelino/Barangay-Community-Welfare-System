# Barangay Community Welfare System

A desktop prototype for organizing basic barangay resident and community-service workflows. The project was built in Python with Tkinter and includes separate interfaces for residents and administrators.

## Features

- User login and account-registration screens
- Resident information management
- Community-service request details
- Feedback submission
- Resident dashboard
- Administrator dashboard
- Custom Tkinter interfaces with image-based assets

## Technology stack

- Python
- Tkinter
- Local image assets

## Project structure

The main application files are inside `BCWS_PROJECT/`, including:

- `Login.py`
- `Sign_up.py`
- `dashboard.py`
- `AdminDashboard.py`
- `ResidentInformation.py`
- `RequestDetails.py`
- `Feedback.py`

## Running the project

1. Install Python 3.
2. Clone this repository.
3. Open the `BCWS_PROJECT` directory.
4. Update the local file paths used by the Python scripts so they point to the repository on your computer.
5. Run:

```bash
python Login.py
```

## Important setup note

Some scripts currently contain absolute Windows paths for image assets and navigation between Python files. Replace those paths with paths that match your local project directory before running the application.
